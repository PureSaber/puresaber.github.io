Python 数据处理

适合写过一点代码、想把 CSV 处理成可用数据表的人。

  1. 写一个小函数。 在Python 官方教程里读控制流程、数据结构和模块，用函数计算一组数的平均值，并处理空列表。
  2. 读入一张成交表。 用 csv.DictReader 读取日期、品种、成交量三列，转换成交量类型，并把缺失或无效的行写进单独的文件。
  3. 按日期和品种汇总。 用 dict 累加成交量，或在 JupyterLab 里用 pandas 做同样的分组计算。

完成标准： 用三行手算样本核对结果，把汇总导出为新的 CSV。

SQL 查询

从筛选一张表开始，练到能解释两张表连接后的行数。

  1. 先筛选，再排序。 跟着 SQLBolt 练 SELECT、WHERE 和 ORDER BY，找出某段日期内成交量最大的几笔记录。
  2. 把明细汇总成日报。 用 GROUP BY 与 SUM 按品种和日期汇总。汇总前先确认每行代表一笔成交。
  3. 连接品种表。 在 DuckDB 里，用 LEFT JOIN 为日报补上品种名。先检查品种表里的代码是否唯一，再比较连接前后的行数。

完成标准： 留下一条可重跑的查询，能说明缺失品种名的成交记录如何保留。

Git 与开源协作

用一个小仓库练习从改动到合并的完整过程。

  1. 看懂一次提交。 跟着《Pro Git》中文版的基础章节修改 README，用 git status 和 git diff 看清改动，然后暂存、提交。
  2. 在分支上做一次小改动。 新建分支，给 README 增加一条可执行的使用示例，提交后推送到 GitHub。
  3. 发起并检查 Pull Request。 用 GitHub 网页或 GitHub CLI 发起 PR。写明改了什么、怎么检查，在差异页复查后合并。

完成标准： 主分支出现新示例，PR 里能找到对应的改动和检查结果。
