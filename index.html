我的实用工具箱

把开发、开源维护和量化研究用得上的工具放在一起，也收录语言教程和数据资料。标题直达对应入口。

  • 资源

工具

编程与开源

  • OpenCode

    在终端里读项目、梳理代码和辅助修改。接手一个新仓库时，可以先用它找项目入口、测试命令和关键配置。

  • GitHub CLI（gh）

    在终端查看 Pull Request、Issue 和 Actions 状态。维护多个仓库时，常用 gh pr list 和 gh run list 快速切换检查。

  • Visual Studio Code

    在编辑器里浏览仓库、修改文件和调试代码。想在同一个窗口里看代码、终端和 Git 改动时可以用它。

  • uv

    管理 Python 环境和项目依赖。把同一套依赖带到另一台机器或 CI 时，可以用锁文件同步环境。

量化与数据

  • JupyterLab

    用 Notebook 做策略复现的单步检查，例如抽查信号计算、对齐交易日、对照研报图表。

  • AKShare

    用 Python 探索股票、期货、基金等公开财经数据。接入策略前，先对照原始数据源确认字段、时间戳和复权口径。

  • pandas

    清洗行情表、合并交易日并计算滚动指标。适合把原始数据整理成回测需要的表格。

  • DuckDB

    用 SQL 查询本地 CSV 或 Parquet，适合快速抽取样本、查重复行和对比文件字段。

资源

语言与开发学习

  • CS 自学指南

    按方向查找计算机课程、教材和实践资源。想补一块知识时，可以从感兴趣的主题找课程和配套练习。

  • Python 官方教程（中文）

    已经有一点编程基础的话，可以从函数、数据结构和模块开始补 Python，再动手写一个读写 CSV 的脚本。

  • MDN 学习 Web 开发

    按 HTML、CSS、JavaScript 学网页开发。想给自己的 GitHub Pages 加导航、表单或交互时，可以从相应章节查起。

  • 《Pro Git》中文版

    遇到分支、合并和回退的问题时，按章节查命令和示例。也可以跟着 Git 基础章节练一次完整的提交流程。

  • SQLBolt

    在浏览器里边读边做 SQL 练习。可以从查询、连接和聚合练起，再拿自己的数据验证。

市场数据与核对

  • 上海期货交易所 · 日周数据

    查看上期所期货和期权的日交易快讯、周行情及每日结算参数，用于抽样核对第三方数据。
